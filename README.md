# The Robot Pickup Line Championship

"I've been on 1% all night, and then you walked in like a charging cable."

A one-line pickup line a robot would use: it has been running on 1% battery all night, and then you walked in like a charging cable — the joke grows out of being a machine (battery, charging), lands from an unexpected angle, and stays charming.

Entry for the [Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) on make.fun.

## How it works

`main.ts` (Node 22) writes the pickup line — exactly 72 characters, no trailing newline — to `/output/entry.txt`, guarded by a non-blank check and the 200-character limit.

Run it with:

```sh
node main.ts
```
